# Density — Video Editor

iPhoneとPCのブラウザで使う、スマホ操作を中心に設計した汎用動画エディター。素材は端末内で処理し、外部へアップロードしません。

## GitHub Pagesで使う

1. このリポジトリの **Settings → Pages** を開く。
2. **Build and deployment → Source: Deploy from a branch** を選ぶ。
3. **Branch: main / Folder: /docs** にして Save。
4. 公開処理が完了したら https://yumeai-fantasy88.github.io/video-editor/ を開く。

`docs/` にビルド済みファイルを含めているので、使う人のPCにNode.jsやResolveをインストールする必要はありません。GitHubはアプリを配信するだけで、動画処理は端末内で実行します。

## 実装した操作

- 動画・画像の連結、トリミング、分割、複製、並べ替え（前後ボタン）
- 秒単位の希望尺、0.001刻みの速度入力（0.05〜20倍）、フレーム換算
- 元音声の独立トラックへの分離、BGM・効果音追加、音量・開始位置・音声フェード
- 日本語テキスト、SRT読み込み、複数のシステムフォント、ローカルフォント追加、縁取り、色、背景、位置、表示時間
- 映像フェード、クロスフェード、回転、固定ズーム
- デンシティー、暗部集中、ハイライト保護、6色別デンシティー、露出、彩度、コントラスト、色温度、色かぶり、シャドウ、ハイライト、フェード
- 調整前後の切り替え、全クリップへのカラー適用、プリセット保存／JSON移動
- 編集設定のJSON保存／読込、元素材の再接続、元に戻す／やり直す
- 横・縦・正方形・4:3、24/25/30/50/60fps、H.264/AAC MP4書き出し

## 基本の使い方

素材を追加 → クリップをタップ → 下部の編集パネルで調整 → 書き出し → 完成したMP4を保存。

分割は再生位置をクリップの途中へ動かして実行します。クロスフェードは前後のクリップを重ねるため全体が短くなります。

「希望する尺」は出力フレームへ丸めた長さを使って速度を計算します。全体の出力尺もフレーム単位です。速度変更はフレームの選択・反復で行い、光学フローの補間はありません。音声が付いたまま速度を変えると音程も変わります。音声の速さを保ちたい場合は、先に音声を分離してください。

「編集設定を保存」でダウンロードするJSONに動画データは含みません。再読込後や別端末では「素材を再接続」で同名・同サイズの元ファイルを選び直します。独自フォントも再選択が必要です。自動クラウド同期はありません。

## カラーと書き出しの範囲

プレビューと書き出しは同じ合成・字幕・WebGLカラー処理を使用します。デンシティーは彩度に応じた輝度低下を独立制御する独自実装で、Resolveの再現や特定フィルムの物理シミュレーションではありません。

表示基準のSDR処理です。RAW、Logの自動変換、HDRの厳密なトーンマッピング、広色域／10bitの色管理、外部LUT読み込み、カラーホイール、スコープは未対応です。HDR素材は先にSDRへ変換してください。OSのフォント、画面の表示特性、圧縮、縮小表示による差は生じます。

プレビューは長辺960px。書き出しは長辺1920pxまたは1280pxを選択し、16:9では1920×1080／1280×720、9:16では1080×1920／720×1280、4:3では1920×1440／1280×960です。

最新のSafari/Chrome等でWebCodecsの映像デコードとH.264エンコード、WebGLが必要です。読み込みコーデックは端末依存。AACエンコードはネイティブ非対応時に同梱WASMエンコーダーを使用します。非対応の映像書き出しを無音・偽MP4として成功扱いにはしません。

完成ファイルをメモリに保持するため、長尺／高ビットレートではメモリ不足になることがあります。最初は短い素材で試してください。書き出し中に画面を閉じる・別アプリへ移ると中止します。iPhone実機・ブラウザ上の書き出しはこの初回実装時には未検証です。

## 開発

Node.js 22以上。`npm ci` → `npm test` → `npm run check` → `npm run build`。
`src/` を変更したら `docs/` を再ビルドし、両方をコミット・プッシュします。Pagesで上記設定を済ませれば、docsの更新が公開に反映されます。

自動テストは尺・クロスフェード・分割・SRT・プロジェクト検証・音声配置／フェード／ミックスなどを検証します。実機の操作性、デコード、WebGLの出力色、最終映像のエンコードは別途実機確認が必要です。
